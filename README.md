# type

D를 위한 커스텀 수치 타입 라이브러리. 분수(`fra`)와 IEEE 754-2008 10진 부동소수점 두 인코딩(`bid`, `dpd`)을 제공합니다.

## 설치

`dub.json`에 추가:

```json
"dependencies": {
    "rnjswldbf_2014": "~>0.1.0"
}
```

```d
import type.type;
```

## 핵심 타입

| 타입 | 용도 | 정밀도 |
|------|------|--------|
| `fra` | 유리수 분수 (`num`/`den`) | `long` 범위 내 정확 |
| `bid` | 10진 부동소수점, 계수를 `BigInt`로 저장 | 임의정밀도, 정확 |
| `dpd` | 같은 값을 10비트 declet으로 압축 저장 | 임의정밀도, 정확 |

`bid`와 `dpd`는 **같은 값을 다른 방식으로 저장**할 뿐, 연산 결과는 동일합니다. IEEE 754-2008이 정의한 두 가지 10진 인코딩에 각각 대응합니다.

- **BID** (Binary Integer Decimal): 계수를 이진 정수 하나로 저장
- **DPD** (Densely Packed Decimal): 10진수 3자리를 10비트로 압축해 저장

## 선언

세 타입 모두 정수·문자열·소수 리터럴로 바로 선언됩니다.

```d
bid a = 1;               // 정수
bid b = "1.5";           // 문자열
bid c = 1.5;             // 소수 리터럴
bid d = 0.12;            // 0.12 (내부 double이 0.11999...여도 정확히 복원)

dpd e = "2.25";
fra f = 5;               // 5/1
fra g = "3/4";           // 3/4
fra h = "0.75";          // 3/4 (약분됨)
```

### ⚠️ 17자리 규칙

따옴표 없는 소수 리터럴은 **유효숫자 약 17자리까지만** 정확합니다.

```d
bid ok  = 3.37981234;    // 9자리  -> 3.37981234           정확
bid bad = 0.04714038928745574865871078547801351068934;
                         // 41자리 -> 0.04714038928745575  잘림!
bid good = "0.04714038928745574865871078547801351068934";
                         // 41자리 전부 정확
```

D 문법상 따옴표 없는 `1.5`는 컴파일 단계에서 이미 `double`로 변환된 뒤 생성자에 전달됩니다. 라이브러리는 "그 double과 정확히 같은 비트값으로 다시 파싱되는 가장 짧은 소수 문자열"을 찾아 복원하므로(Python의 `Decimal(str(x))`와 같은 기법) 짧은 리터럴은 원래 쓴 그대로 잡히지만, `double`이 애초에 담지 못한 자릿수는 되살릴 수 없습니다.

**17자리를 넘는 정밀도가 필요하면 반드시 따옴표를 쓰세요.**

## 연산

```d
bid x = "1.5";

x + 1            // 2.5   — 일반 숫자와 혼용 가능
1 + x            // 2.5   — 좌우 어느 쪽이든
x - "0.5"        // 1.0
x * 3            // 4.5
x > 1            // true
x == "1.50"      // true  — 값 비교 (표기가 달라도 동일)
```

나눗셈은 자릿수를 명시합니다 (반올림: round-half-up):

```d
bid one = 1, three = 3;
one.divide(three, 21)     // 0.333333333333333333333  (21자리)
```

`fra`와도 정확히 상호운용됩니다 (double 근사를 거치지 않고 `계수 × 10^지수`를 약분):

```d
fra half = fra(1, 2);
bid quarter = "0.25";
half + quarter            // 3/4
```

> `fra`는 `num`/`den`이 `long`이라, 약분 후에도 `long` 범위를 넘으면 조용히 틀린 값을 주는 대신 예외를 던집니다.

## DPD 비트 인코딩

`dpd`는 값을 3자리씩 묶어 10비트 declet에 압축합니다.

```d
dpd v = "0.476190476190476190476";
v.digits.length      // 21
v.pack()             // ushort[7] — 10비트 declet 7개
v.pack()[0]          // 0b1001110110
```

| 메서드 | 설명 |
|--------|------|
| `pack()` | 자릿수를 declet 배열로 압축 |
| `dpd.unpackDigits(declets)` | declet 배열을 자릿수로 복원 |
| `toBid()` / `dpd.fromBid(b)` | `bid`와 상호 변환 |
| `bcdToDpd(d2,d1,d0)` | 3자리 → 10비트 (저수준) |
| `dpdToBcd(declet, ...)` | 10비트 → 3자리 (저수준) |

인코딩/디코딩은 스펙 저자 Mike Cowlishaw가 공개한 불리언 공식을 그대로 구현했으며, **0~999 전 조합(1000개)에 대한 왕복 테스트**로 검증됩니다.

## 방정식 풀이

`solve(변수명, 방정식)` — 1~3차 방정식의 해를 구합니다.

```d
solve("x", "x + 5 = 12")             // ["x: 7"]
solve("x", "x^2 - 5x + 6 = 0")       // ["x: 3", "x: 2"]
solve("x", "x^2 = 2x + 3")           // ["x: 3", "x: -1"]   — 양변에 항이 있어도 됨
solve("x", "x^3 - 6x^2 + 11x - 6 = 0")  // ["x: 3", "x: 2", "x: 1"]
solve("y", "2y - 8 = 0")             // ["y: 4"]            — 변수명 자유
```

표기는 `2*x`, `2x`, `x^2` 모두 되고 공백은 자유입니다. 우변을 생략하면 `= 0`으로 봅니다.

**복소근도 반환합니다:**

```d
solve("x", "x^2 + 1 = 0")   // ["x: 0 + 1i", "x: 0 - 1i"]
solve("x", "x^3 = 8")       // ["x: 2", "x: -1 + 1.732050808i", "x: -1 - 1.732050808i"]
```

중근은 한 번만 나옵니다 (`x^3 - 3x^2 + 3x - 1 = 0` → `["x: 1"]`). 해가 없거나 무한하면 `["no solution"]` / `["infinitely many solutions"]`를 반환하고, **4차 이상은 조용히 틀린 답을 주는 대신 예외를 던집니다.**

> `solve()`의 내부 계산은 `double` 기반이라 약 17자리까지입니다. 해는 부동소수점 잡음을 정리해 출력하므로 `1.9999999999999998` 대신 `2`로 나옵니다.

### 임의정밀도 풀이

`solvePrecise(변수명, 방정식, 자릿수)` — 소수점 이하 원하는 자릿수만큼 정확하게 풉니다.

```d
solvePrecise("x", "x^2 - 2 = 0", 50)
// ["x: 1.41421356237309504880168872420969807856967187537695",
//  "x: -1.41421356237309504880168872420969807856967187537695"]

solvePrecise("x", "x^3 - 2 = 0", 50)[0]
// "x: 1.25992104989487316476721060727822835057025146470151"

solvePrecise("x", "x^3 - 3x + 1 = 0", 20)
// ["x: 1.53208888623795607040", "x: 0.34729635533386069770",
//  "x: -1.87938524157181676811"]
```

`double`을 전혀 거치지 않습니다. 계수부터 `bid`로 정확히 파싱하고, 1차·2차·중근 3차는 닫힌 형태로 정확히, 나머지 3차는 Newton법을 **정확 산술로** 반복해 요구 자릿수까지 수렴시킵니다.

**실근을 `dpd` 값으로 받기:**

```d
auto roots = solveRealRoots("x", "x^2 - 2 = 0", 45);
roots[0].toString()        // 1.414213562373095048801688724209698078569671875
roots[0].digits.length     // 46
roots[0].pack().length     // 16   — 10비트 declet
```

복소근은 `solvePrecise`가 문자열로 반환하고, `solveRealRoots`는 실근만 골라 돌려줍니다.

### 임의정밀도 제곱근·세제곱근·반올림

`bid`와 `dpd` 모두 값에서 바로 호출합니다. 인자는 소수점 이하 자릿수입니다.

```d
dpd two = 2;
two.sqrt(40)    // 1.4142135623730950488016887242096980785696
two.cbrt(40)    // 1.2599210498948731647672106072782283505702
two.sqrt(40).round(10)   // 1.4142135624

bid b = 2;
b.sqrt(60)      // 1.414213562373095048801688724209698078569671875376948073176679
```

> `sqrt`/`cbrt`는 **절사**합니다 (구한 근이 실제값을 넘지 않도록). 반올림한 값이 필요하면 한 자리 더 구해서 `round()`를 쓰세요 — `two.sqrt(45).round(40)`.

동일 기능의 자유 함수와 저수준 함수도 있습니다.

| 함수 | 설명 |
|------|------|
| `bidSqrt(v, scale)` / `bidCbrt` / `bidRound` | 위 메서드의 자유 함수 형태 |
| `refineRoot(coeffs, guess, m, scale)` | Newton법 근 정밀화 (`m`은 중근 차수) |
| `isqrt(n)` / `icbrt(n)` | `BigInt` 정수 제곱근·세제곱근 |

## 기타 타입

`dfloat`, `dec`, `posit`은 초기 실험적 타입으로, **내부적으로 `double` 하나만 감싸고 있습니다.** 즉 10진 정확도나 posit 산술을 실제로 구현하지 않으며, 이름과 필드(`dec.mode`, `posit.bits`)는 라벨에 가깝습니다. 정확한 10진 계산이 필요하면 `bid`/`dpd`를 쓰세요.
